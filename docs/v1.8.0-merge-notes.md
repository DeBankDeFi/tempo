### D2: Cargo.toml alloy-rpc 依赖块冲突 [decided]

- 上游：alloy 系列 `2.0.4 → 2.0.5`，**新增** `alloy-rpc-client = { version = "2.0.5", default-features = false }`，**删除** `alloy-rpc-types-trace`

- 影响：debank-rpc 的 LocalizedTransactionTrace 引用继续可用，无 breaking
